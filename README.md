## 💡 La idea

La mayoría de calendarios cumplen su función, pero se sienten iguales y estáticos. **365 días de luz** busca que organizar tu tiempo sea algo visualmente agradable y adaptado a ti, combinando utilidad real con una interfaz viva y expresiva.

## ✨ Características

### 🧰 Utilidades
- Gestión de eventos y recordatorios
- Herramientas extra que van más allá de un calendario tradicional
- Vistas pensadas para el uso diario en el celular

### 🎨 Personalización
- Temas y paletas de colores configurables
- Elementos visuales dinámicos y animaciones
- Interfaz adaptable al gusto de cada usuario

## 🚀 Cómo verlo localmente

```bash
git clone https://github.com/ash300kl/365-dias-de-luz.git
cd 365-dias-de-luz
```

Abre `index.html` en tu navegador. Para la mejor experiencia, activa la vista de dispositivo móvil en las herramientas de desarrollador (`F12` → ícono de celular).
